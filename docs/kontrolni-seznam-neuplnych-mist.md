# Kontrolní seznam neúplných / nejistých míst v pravidlech

Zdroj: kompletní sweep artefaktu "Pravidla DrD + domácí pravidla" (68 459 řádků). Nalezeno **283** označených míst (215 core, 68 homebrew). Tento seznam v artefaktu samotném dosud neexistoval jako souhrn — vznikl teď a slouží jako podklad pro dofocení a doplnění před finálním importem do databáze.

**Jak seznam číst:**
- **A** = má známou konkrétní stranu → dej přednost, fotíš přesně tohle
- **B** = chybí celá tabulka, strana není známá → najdi v uvedené kapitole
- **C** = homebrew nejasnost → není co fotit, je potřeba to sám/sama doplnit nebo rozhodnout, protože je to váš vlastní text, ne sken
- **D** = drobná nejasnost/poškození bez známé strany → nízká priorita, řešit až zbyde čas
- **E** = zkontrolováno, ale je to jen informační poznámka nebo už vyřešené místo → není potřeba nic dělat, uvedeno jen pro úplnost
